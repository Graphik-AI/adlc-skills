# Adaptations in 0.1.0

This is a local candidate, not an owner-approved release. The source manifest
[records each imported file](sync-sources.json), its original and packaged hashes,
identity, notice and adaptation. Changes below apply in the bodies, support files
and metadata. Shared rules are loaded through the [contract](references/adlc-contract.md).
