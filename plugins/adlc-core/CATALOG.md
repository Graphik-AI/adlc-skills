# Skill catalog

The package contains 17 selected workflows and four helpers. Each addresses a specific need. Helpers support another workflow when needed.

| Skill | Role | Use |
| --- | --- | --- |
| [`acquire-codebase-knowledge`](skills/acquire-codebase-knowledge/SKILL.md) | Selected | Creates durable documentation for an existing repository when you explicitly request mapping or onboarding. |
| [`code-review`](skills/code-review/SKILL.md) | Selected | Assesses the requested diff against requirements and project standards, including relevant uncommitted work. |
| [`codebase-design`](skills/codebase-design/SKILL.md) | Helper | Supports design of a module interface when its responsibilities or dependencies are unclear. |
| [`deslop`](skills/deslop/SKILL.md) | Selected | Removes unnecessary material from the task diff while preserving behavior and safeguards. |
| [`domain-modeling`](skills/domain-modeling/SKILL.md) | Selected | Clarifies domain terms and relationships for a glossary, design decision, or implementation. |
| [`frontend-testing-debugging`](skills/frontend-testing-debugging/SKILL.md) | Selected | Checks rendered UI and interactions or investigates browser failures in the authorized running app. |
| [`grill-with-docs`](skills/grill-with-docs/SKILL.md) | Selected | Resolves consequential choices through a focused interview and records useful decisions. |
| [`grilling`](skills/grilling/SKILL.md) | Helper | Examines an unresolved decision through a focused human interview. |
| [`implement`](skills/implement/SKILL.md) | Selected | Builds a bounded task, spec, or ticket with relevant checks and review. |
| [`implement-spec`](skills/implement-spec/SKILL.md) | Selected | Coordinates implementation when an agreed spec has dependencies that benefit from separate implementers. |
| [`post-implementation`](skills/post-implementation/SKILL.md) | Selected | Records completion, evidence, and remaining work within the authorized task. |
| [`pr`](skills/pr/SKILL.md) | Selected | Writes a PR description that matches the final change and verification evidence. |
| [`prototype`](skills/prototype/SKILL.md) | Helper | Builds a throwaway UI or logic experiment to answer a specific design question. |
| [`research`](skills/research/SKILL.md) | Helper | Answers a bounded factual question using primary sources and records the evidence. |
| [`simplify`](skills/simplify/SKILL.md) | Selected | Improves unclear changed code while preserving behavior, error handling, and security. |
| [`systematic-debugging`](skills/systematic-debugging/SKILL.md) | Selected | Traces an unexplained failure through the relevant code and runtime before proposing a fix. |
| [`tdd`](skills/tdd/SKILL.md) | Selected | Develops a behavior change through a failing test, a supported fix, and regression checks. |
| [`thermo-nuclear-code-quality-review`](skills/thermo-nuclear-code-quality-review/SKILL.md) | Selected | Assesses a concrete structural concern in the requested diff and separates defects from optional redesign. |
| [`to-spec`](skills/to-spec/SKILL.md) | Selected | Records agreed work in a specification detailed enough to implement. |
| [`to-tickets`](skills/to-tickets/SKILL.md) | Selected | Divides agreed work into testable pieces and identifies their dependencies. |
| [`wayfinder`](skills/wayfinder/SKILL.md) | Selected | Tracks unresolved decisions and their dependencies across sessions. |

The [Claude Code guide](guides/claude-code.md) and [Codex guide](guides/codex.md) explain installation, source selection, and invocation. The [verification record](VERIFICATION.md) lists tested capabilities and limits.
