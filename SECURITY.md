# Security

Report vulnerabilities privately through this repository's
[private vulnerability reporting](https://github.com/Graphik-AI/adlc-skills/security/advisories/new).
Include the affected revision, file, reproducible trigger, and expected impact.
Use synthetic or redacted evidence; do not include credentials or customer data.
Do not post sensitive reports in public issues.

Skills provide instructions to an agent and can influence commands, file access,
and external actions. Review the source before installation. Project authorization,
sandbox restrictions, and the host's security controls continue to apply.
A skill's availability is not permission to deploy, publish, or contact third parties.

Package checks verify integrity and safe synthetic helper behavior. They do not
establish that every workflow or external service integration is secure.
