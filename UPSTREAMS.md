Vecton's adaptations include proportionate task depth, carried-forward authority,
acceptance-diff coverage, safe scanner output, and explicit host limitations.
[ADAPTATIONS.md](plugins/adlc-core/ADAPTATIONS.md) explains these changes;
[sync-sources.json](plugins/adlc-core/sync-sources.json) records exact source
identities, qualifications, original hashes, and packaged hashes.
These repository links identify the projects; the per-file manifest identifies
the imported revisions. Retain both original copyright notices and credits when redistributing.

additions are [MIT-licensed](plugins/adlc-core/notices/Vecton-MIT.txt);
[local source notes](plugins/adlc-core/notices/LOCAL-SOURCES.md) describe the boundary.
